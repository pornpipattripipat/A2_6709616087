What I Built

รายละเอียดของงาน: ในงาน A1 นี้มีส่วนประกอบสำคัญได้แก่ โครงสร้าง Semantic HTML และ การตกแต่งด้วย CSS

Client / Server Analysis: ในขณะที่เปิดเว็บไซต์จากเครื่องของตนเองจะมีเพียง Client เกิดขึ้นเพื่อทำหน้าที่อ่านและแสดงผลไฟล์ HTML/CSS แต่จะยังไม่มี Server ทำงานอยู่ เนื่องจากไม่ได้มีการเรียกขอข้อมูลผ่านโปรโตคอล HTTP/HTTPS ไปยัง Web Server

How I Built It

ขั้นตอนสำคัญในการพัฒนางานนี้ ประกอบด้วย:

  1. วางโครงสร้างหน้าเว็บและกำหนดข้อมูลที่ต้องใช้
  2. เขียนโครงสร้างด้วย Semantic HTML เช่น header, main, section
  3. ตกแต่งความสวยงาม จัดเลย์เอาต์ ด้วย CSS แยกไฟล์

เครื่องมือที่ใช้: VS Code สำหรับเขียนโค้ด

Reflection

  • ปัญหาหรือความท้าทาย: การจัดตำแหน่งรูปภาพให้พอดีกับข้อความตามที่ต้องการอีกทั้งคำสั่งที่ไม่คุ้นเคยทำให้ใช้เวลาในการทำคุ้นเคย
    วิธีรับมือ: ทำความเข้าใจจากเอกสารของอาจารย์และปรึกษา ai เพื่อทำความใจกับคำสั่งที่ไม่คุ้นเคย
  • สิ่งที่เข้าใจมากขึ้น: เข้าใจการแยกโครงสร้างเนื้อหาและกการตกแต่งด้วย CSS มากขึ้น
  • สิ่งที่อยากปรับปรุงต่อ: เวลาที่ใช้ในการทำงานและไอเดียสร้างสรรค์ เพราะ ต้องการให้เว็บไซต์ให้ออกมาดูดีกว่านี้และโดดเด่น
